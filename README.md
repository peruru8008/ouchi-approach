# おうちアプローチ

部屋のカップ(初期設定はボールから5.41m)を狙う、シンプルなアプローチゲームです。
使うのは穴あきの練習ボール。iPhoneのカメラで飛んでいくボールを計測し、iPadに練習ボールのままの弾道と転がりを表示します。

## 置き方(この置き方を前提に作っています)

- iPhoneは**ボールの真後ろ**(飛ばす方向の延長線上)、**ボールから1.8m**、**床に近い低い位置**に、**縦向き**で置く
- カメラは飛ばす方向(カップ)に向ける。少し上向きでかまいません(傾きはセンサーで測ります)
- ボールの**境目(2色の境)は、飛ばす方向に向けて縦にまっすぐ**置く
- 部屋はできるだけ明るくする

距離を変えたときは、iPhoneの「計測の設定」→「カメラからボールまでの距離」を合わせてください。

## 遊び方

1. **iPad**:Safariで公開ページを開き、「iPad:画面」を選ぶ → QRコードが出ます
2. **iPhone**:標準の**カメラアプリ**でQRコードを読み取り、表示されたリンクを開く(自動でカメラ役になってiPadにつながります)
3. iPhoneで「カメラを開始」→ カメラと**傾きセンサー(動作と方向)**を許可
4. **最初の1回だけ**:置き場所にボールを置き、映像のボールをタップ → 「ボールをどけてください」と出たら、ボールを手でどけるか、そのまま1球打つ。置き場所を覚えます
5. ボールを置くと自動で見つけ、iPadに緑の「打ってOK」が出ます。打つと、iPadに弾道が出ます

- 構えたときにクラブでボールが隠れても大丈夫です(後ろから見ると隠れるのが普通です)
- iPadの「打つ場所」で**マット/ラフ**を選べます。ラフのときは、芝が挟まる分スピンを半分にして計算します
- iPadの「設定と試し打ち」で、**ボールからカップまで**(初期5.41m)と**グリーンの手前まで**(初期2.63m)を部屋に合わせられます
- 置き場所は端末に覚えておきます。置き場所やカメラを動かしたら、iPhoneの「計測の設定」→「置き場所を登録し直す」

## 計測のしくみ

1. **置き場所だけを見る**:登録した置き場所のまわりだけを、毎コマ元の解像度で見ます。何もないときの置き場所と比べて、丸い物が0.2秒止まったら「打ってOK」
2. **打ったら追う**:置き場所のボールが消えたら、上へ飛んでいくボールを毎コマ探します。ボールの2色・大きさ・上へ進むことを確かめて、クラブや体の動きと区別します
3. **3Dに直す**:ボールが遠ざかるほど小さく写ることと、ボールまでの距離(1.8m)から、ボールの3Dの位置を出します。傾きセンサーの重力の向きを使って、重力と空気抵抗の入った軌道を当てはめ、**球速・打ち出し角・左右の向き**を出します(打ってから約0.25秒で計算できます)
4. **回転**:スピン量は、球速と打ち出し角からクラブとの衝突の物理で推定します。飛んでいる間の境目の傾きから**回転軸の傾き**(曲がり)を読みます
5. **自動の合わせ込み**:着地まで追えた球は、その軌道に合うように空気抵抗の補正を少しずつ合わせます(打つほど部屋の実際の飛び方に近づきます)

送ってもらった60fpsの動画(後方・低い位置、約100秒)を、アプリと同じ計算で通して確かめました。登録後に打った5球のうち4球を計測でき(球速7.3〜10.1m/s・打ち出し角18〜26°・左右±2°以内)、残りの1球は誤った値を出さずに「もう一度どうぞ」になりました。素振りやクラブの動きを打球と取り違えたことはありませんでした。

## 合わせ込み(iPhoneの「計測の設定」)

- **カメラからボールまでの距離**:球速の計算の基準です。メジャーで測った値にしてください
- **練習ボールの重さ・直径・反発係数**:初期値は直径42mm・5g・0.55。反発係数は1mの高さから落として跳ね返った高さを入れると自動で計算します
- **空気抵抗の補正**:ふだんは自動。手動で合わせたいときは、1球打ったあとに最初に落ちた所までの距離を入れます

## 発熱と電池への配慮

- iPhone:置き場所や飛んでいるボールのまわりだけを読みます。20秒触らないと画面を真っ黒にし(タップで戻る)、10分打たないとカメラを休止します
- iPad:3D画面は、ボールや視点が動いているときだけ描き直します

## セキュリティ

- **カメラ映像は端末の外に出ません**。iPhoneのSafariの中で解析し、保存も送信もしません。送るのは数値と状態だけです
- 傾きセンサーの値は、カメラの傾きの計算にだけ使い、送信も保存もしません
- 端末に保存するのは設定と、置き場所の位置と6×6の平均色(空の置き場所の確認用)だけです
- 画面を離れると、カメラとセンサーを自動で止めます
- iPhoneとiPadは暗号化された直接通信(WebRTC)でつながり、データを中継するサーバー(TURN)は使いません。最初のつなぎ合わせにだけ公開の接続サーバーを使います
- 接続コードはランダムな8文字です。iPadは同時に1台しか受け付けず、受け取ったデータは中身を検査してから使います。QRコードのコードは、読み取り後にアドレスバーから消します
- 外部サイトからプログラムや画像を読み込みません。ライブラリ(three.js・PeerJS・qrcode-generator)は `vendor/` に同梱し、読み込み先を自分のサイトに制限する設定(Content-Security-Policy)を入れています

## 更新のしかた

GitHubのリポジトリで「Add file」→「Upload files」を開き、変わったファイル(index.html・style.css・app.js・README.md)を選んで「Commit changes」を押します。同じ名前のファイルは上書きされます。1〜2分で公開ページに反映されます。

## うまくいかないとき

- **「打ってOK」が出ない**:置き場所を登録し直す。ボールの後ろ(画面でボールの上側)に、ボールと同じ色の物がないようにする
- **「飛んでいくボールが見つかりませんでした」**:部屋を明るくする。iPhoneを動かしていないか確かめる
- **傾きが「取れません」**:「カメラを開始」のときに出る「動作と方向へのアクセス」を許可してください。許可しなかった場合は、設定 → Safari → 詳細 → Webサイトデータ でこのサイトのデータを消してから開き直すと、もう一度聞かれます
- **iPadに「接続サーバーに届きません」**:ネット接続を確認してください
