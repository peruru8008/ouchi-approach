# おうちアプローチ — 公開と使い方の手順

自宅用のアプローチ計測器です。iPhoneのカメラでボールを計測し、iPadに弾道と数値を表示します。

## このフォルダの中身

- `index.html` … ページ本体
- `style.css` … 見た目
- `app.js` … 計測・通信・弾道計算のプログラム
- `vendor/` … 3D表示(three.js)と通信(PeerJS)のライブラリ。外部サイトから読み込まず、このフォルダに同梱しています

## 1. GitHubアカウントを作る

1. https://github.com/signup を開きます
2. メールアドレス、パスワード、ユーザー名を入力して登録します
   - ユーザー名は公開URLに入ります(例: `koichi-golf` → `https://koichi-golf.github.io/...`)
3. 届いたメールの確認コードを入力します
4. 設定 → Password and authentication から、2段階認証(Two-factor authentication)を有効にしておくと安全です

## 2. リポジトリ(置き場所)を作ってファイルを上げる

1. 右上の「+」→「New repository」
2. Repository name に `ouchi-approach` と入力し、「Public」を選んで「Create repository」
   - 無料でページを公開するには Public が必要です。公開されるのはプログラムだけで、個人データは含まれません
3. 作成後の画面で「uploading an existing file」をクリック
4. このフォルダの中身(`index.html`、`style.css`、`app.js`、`vendor` フォルダ、この `README.md`)をまとめてドラッグ&ドロップ
   - `vendor` はフォルダごとドラッグしてください
5. 下の「Commit changes」を押します

## 3. ページを公開する

1. リポジトリの「Settings」→ 左メニューの「Pages」
2. 「Build and deployment」の Source を「Deploy from a branch」
3. Branch を `main`、フォルダを `/ (root)` にして「Save」
4. 1〜2分待つと、上部に公開URLが出ます
   - 例: `https://ユーザー名.github.io/ouchi-approach/`

## 4. 遊び方

1. iPadのSafariで公開URLを開き、「iPad:画面(弾道表示)」を選ぶ → 8文字の接続コードが出ます
2. iPhoneのSafariで同じURLを開き、「iPhone:カメラ(計測)」を選ぶ → コードを入力して「接続」
3. iPhoneを三脚に横向きで固定し、ボールを挟んで自分と向かい合う位置(1〜1.5m)に置く
4. 「カメラを開始」→ カメラの使用を許可 → 映像のボールを1回タップして登録
5. ボールが認識されると、iPadに「打ってOK」が出ます
6. 打つと、iPadに弾道と数値(球速・打ち出し角・スピン・キャリー・合計・ピンまで)が出ます
7. 次のボールを同じあたりに置くと、また「打ってOK」になります

どちらの端末も、同じWi-Fiにつないでおいてください。

## セキュリティについて

- **カメラ映像は端末の外に出ません**。iPhoneのSafariの中で解析し、保存も送信もしません。送るのは数値(球速・角度・スピン)と「打ってOK」などの状態だけです
- **画面を離れるとカメラを自動で止めます**。カメラ使用中はSafariのアドレスバーにカメラの表示が出ます
- **iPhoneとiPadは直接つながります**。通信はWebRTCで暗号化されます。最初のつなぎ合わせにだけ、公開の接続サーバー(0.peerjs.com)を使います。そこに渡るのは端末の接続情報で、映像や計測値は通りません。データを中継するサーバー(TURN)は使わない設定にしています
- **接続コードは毎回ランダムな8文字**で、iPadは同時に1台のiPhoneしか受け付けません。受け取ったデータは種類と数値の範囲を検査してから使います
- **外部サイトからプログラムを読み込みません**。ライブラリは同梱し、ページには読み込み先を自分のサイトだけに制限する設定(Content-Security-Policy)を入れています
- 保存するのは計測の設定値とプレイヤー名だけで、この端末の中(ブラウザ)に保存されます

## うまくいかないとき

- **iPadに「接続サーバーに届きません」と出る**:ネット接続を確認してください。公開の接続サーバーが混雑・停止していることもあります
- **iPhoneで「コードが違うか、iPadが待機していません」と出る**:iPadの画面を開いたままにして、コードを入れ直してください
- **「ボールを追えませんでした」が続く**:部屋を明るくする、ボールの後ろを無地にする、「計測の設定」の検出感度を上げる、を試してください
- **数値が本物の感覚とずれる**:「計測の設定」の換算係数と角度補正で合わせます
