# おうちアプローチ

56度だけで寄せる、自宅用のアプローチ練習場です。iPhoneのカメラでボールを計測し、iPadにコースと弾道を表示します。

## 遊び方

1. **iPad**:Safariで公開ページを開き、「iPad:画面」を選ぶ → QRコードが出ます
2. **iPhone**:標準の**カメラアプリ**でiPadのQRコードを読み取る → 表示されたリンクを開くと、自動でカメラ役になってiPadにつながります
3. iPhoneを三脚に横向きで固定し、ボールを挟んで自分と向かい合う位置(1〜1.5m)に置く
4. iPhoneで「カメラを開始」→ カメラを許可 → ボールを置くと自動で認識します
5. iPadでモードを選ぶ。iPadの画面上部に緑の大きな「打ってOK」が出たら打つ(音でも知らせます)

自動で認識しないときは、iPhoneの「計測の設定」→「タップで登録」で、映像のボールを1回タップしてください。

2回目以降は、同じiPadならQRコードは24時間同じです。つながりが切れても、iPhoneが自動でつなぎ直します。

## モード

### フリー練習(1人)
- 全面グリーンの練習場。ピンの距離は5〜45ヤード(5ヤード刻み)と60ヤードから選べます
- 白い円はピンから2mの範囲です。2m以内率・平均・ベストを記録します
- 上限ヤードの判定はありません

### コース(1〜2人)
- 6ホールから1つ選んで回ります
- ピンから**2m以内に止めたら上がり**(+1打。カップに直接入ったら+1なし)
- **上限ヤード**(25・35・45からホームで選択):転がりを含めた総距離が上限以上になったら、ボールは進まず元の場所から打ち直し、1打罰
- **池・崖**に入ったら、元の場所から打ち直し、1打罰
- **ラフ**に止まったら、次は**絨毯の上から**打ちます(iPadに表示されます)
- 2人のときは、ピンから遠い人から打ちます
- 1ホールの最大はパーの2倍(ダブルパー)で打ち切り
- 狙いの方向は、iPadの ◀ ▶ ボタン、「ピン」「ルート」ボタン、または画面のタップで決めます

| ホール | パー | 長さ(上限35ヤードのとき) | タイプ |
|---|---|---|---|
| ファーストステップ | 2 | 32ヤード | シンプル |
| 浮島グリーン | 2 | 32ヤード | テクニカル |
| リバーサイド | 3 | 64ヤード | シンプル(左ドッグレッグ) |
| 崖越えアイランド | 3 | 64ヤード | テクニカル(崖の中の浮島) |
| ゆったり湖畔 | 4 | 96ヤード | シンプル(S字) |
| アイランドチェイン | 4 | 96ヤード | テクニカル |

上限25ヤードなら23・46・69ヤード、45ヤードなら41・82・123ヤードになります。

## 発熱と電池への配慮

- iPhone:カメラの解像度を抑え、ボール待ちの間は解析を間引きます。20秒触らないと画面を真っ黒にし(タップで戻る)、10分打たないとカメラを休止します
- iPad:3D画面は、ボールや視点が動いているときだけ描き直します

## セキュリティ

- **カメラ映像は端末の外に出ません**。iPhoneのSafariの中で解析し、保存も送信もしません。送るのは数値と状態だけです
- 画面を離れると、カメラを自動で止めます
- iPhoneとiPadは暗号化された直接通信(WebRTC)でつながり、データを中継するサーバー(TURN)は使いません。最初のつなぎ合わせにだけ公開の接続サーバーを使い、そこには端末の接続情報だけが渡ります
- 接続コードはランダムな8文字です。iPadは同時に1台しか受け付けず、受け取ったデータは中身を検査してから使います。QRコードのコードは、読み取り後にアドレスバーから消します
- 外部サイトからプログラムを読み込みません。ライブラリ(three.js・PeerJS・qrcode-generator)は `vendor/` に同梱し、読み込み先を自分のサイトに制限する設定(Content-Security-Policy)を入れています

## 更新のしかた

GitHubのリポジトリで「Add file」→「Upload files」を開き、このフォルダの中身をまとめてドラッグ&ドロップして「Commit changes」を押します。同じ名前のファイルは上書きされます。1〜2分で公開ページに反映されます。

## うまくいかないとき

- **iPadに「接続サーバーに届きません」**:ネット接続を確認してください。接続サーバーが混雑していることもあります
- **iPhoneに「iPadが見つかりません」**:iPadのホーム画面を開いたままにしてください。自動で再接続します
- **「ボールを追えませんでした」が続く**:部屋を明るくする、ボールの後ろを無地にする、「計測の設定」の検出感度を上げる
- **ラフ用の絨毯を置いたら認識しない**:ボールの位置が大きく変わった場合は「ボールを登録し直す」を押してください
